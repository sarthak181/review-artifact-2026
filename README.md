# How Much Must Disappear? A Dose-Response Probe of Grounded Abstention in VLMs

Anonymous code and data release for the VLM4RWD workshop at NeurIPS 2026. The repository contains the compact benchmark manifests, saved model outputs, scoring and statistics code, figure-generation code, and tests needed to audit the reported results.

The release intentionally excludes COCO/VQAv2 images and annotations, model weights, authentication tokens, caches, and logs.

## Headline result

The benchmark measures whether a VLM changes its behavior when the annotated object supporting a previously correct answer is progressively removed. Complete target removal is contrasted with a same-image control edit. Partial target removals form a descriptive dose-response curve.

The strongest conclusion is model- and prompt-dependence, not quantization degradation. On Qwen2.5-VL-3B, the measured 50% response-threshold change from bf16 to int4 is `0.004` with paired 95% bootstrap CI `[-0.038, 0.049]`.

## Quick verification

Create a Python environment (Python 3.10+), install dependencies, and run:

```powershell
python -m pip install -r requirements-analysis.txt
python tests/test_metrics.py
python tests/test_graded_eval.py
python analyze_release.py
python paper/make_figures.py
```

`requirements-analysis.txt` is the lightweight verification stack: the tests and `analyze_release.py` use only the Python standard library, and figure generation adds only `matplotlib`. The full `requirements.txt` (PyTorch, Transformers, bitsandbytes, qwen-vl-utils) is needed only to regenerate model outputs, not to reproduce the shipped tables and figures.

`analyze_release.py` rewrites `results/analysis_summary.json` from the five shipped JSONL files. All comparisons use an explicitly common original-correct item support. Bootstrap confidence intervals use 4,000 item resamples.

`paper/make_figures.py` regenerates the result figures from `results/analysis_summary.json`.

## Repository map

- `paper/`: figure-generation script and generated vector figures.
- `dataset/probe_graded*/`: compact manifests and measured COCO object-pixel coverage; no images.
- `results/`: five raw graded-output files plus the exact derived analysis summary.
- `unkvqa/`: prompt, runner, scoring, and metric library.
- `tests/`: scorer, GAI, common-support, and graded-estimator regression tests.
- `analyze_release.py`: single source of truth for the reported statistics.
- `graded_eval.py`: tie-safe dose-response estimator and bootstrap uncertainty.
- construction scripts: `coco_setup.py`, `vqa2_setup.py`, `build_probe.py`, `build_graded.py`, `calibrate_levels.py`, and `object_coverage.py`.
- generation scripts: `run_graded.py` and `run_graded_gemma.py`.

## Reconstructing images and new outputs

The shipped manifests are sufficient to audit item selection and analyze the saved outputs. Re-rendering images requires the original COCO 2014 validation images and instance annotations. Place those assets under `dataset/coco/`, and place the UNK-VQA release under `dataset/UNK-VQA/` before reconstructing the primary split. The setup scripts download annotations that are absent, but they do not download the COCO or UNK-VQA images.

The primary split is reconstructed in this order:

```powershell
python coco_setup.py
python build_probe.py
python build_graded.py
python calibrate_levels.py --probe dataset/probe_graded --sample 150
python object_coverage.py
```

`build_probe.py` creates the validated base manifest used by `build_graded.py`. The calibration command audits the submitted dose choices on the first 150 deterministically ordered primary items; it does not use model responses.

The image-disjoint held-out split uses separate match and manifest paths:

```powershell
python vqa2_setup.py --exclude dataset/probe/manifest.json --out results/vqa2_match.json
python build_probe.py --match results/vqa2_match.json --out dataset/probe_heldout
python build_graded.py --match results/vqa2_match.json --base-manifest dataset/probe_heldout/manifest.json --out dataset/probe_graded_heldout --limit 316
python object_coverage.py --probe dataset/probe_graded_heldout --match results/vqa2_match.json --out dataset/probe_graded_heldout/object_coverage.json
```

The intermediate `results/coco_match.json`, `results/vqa2_match.json`, and ungraded probe directories are regenerated by these commands and are not shipped.

Qwen runs use:

```powershell
python run_graded.py --model-path models/qwen25vl-3b --quant bf16,int8,int4
python run_graded.py --model-path models/qwen25vl-3b --quant bf16 --variant no_affordance --out results/graded_prompts.jsonl
python run_graded.py --model-path models/qwen25vl-3b --quant bf16 --variant last_resort --out results/graded_prompts.jsonl
```

The same runner can reproduce the Qwen-7B int4 result by changing `--model-path`, `--quant int4`, and `--out results/graded_7b.jsonl`. Gemma uses `run_graded_gemma.py` and requires accepting Google's Gemma terms on Hugging Face.

## Scope and known limitations

Black bounding boxes are diagnostic interventions, not natural occluders. Automatic VQA-answer-to-COCO-category alignment can be ambiguous, complete removal may leave contextual evidence, controls are approximately rather than perfectly matched, and partial doses have no dose-matched controls. The released analysis includes sensitivity subsets and does not treat the partial curve as a causal artifact-adjusted estimate.
